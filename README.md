# پر کردن کارت (اپ اندروید)

## اجرا
1. پوشه پروژه را در **Android Studio** (نسخه Hedgehog یا جدیدتر) باز کنید (File ▸ Open).
2. صبر کنید Sync گریدل تمام شود (نیاز به اینترنت دارد). اگر پیشنهاد آپدیت Gradle/AGP داد، تأیید کنید.
3. گوشی را با USB و حالت Developer وصل کنید و Run بزنید، یا از **Build ▸ Build APK(s)** فایل APK بگیرید.

## کارکرد
- ۸ کادر عددی روی تصویر؛ ارقام همیشه با **فونت وزیرمتن بولد، مشکی و فارسی** نمایش داده و ذخیره می‌شوند.
- تاریخ شمسی با انتخابگر (سال/ماه/روز) تعیین می‌شود؛ پیش‌فرض تاریخ امروز است.
- دکمه «خروجی» تصویر نهایی را با کیفیت کامل (PNG) در گالری، پوشه `Pictures/PersianCard` ذخیره می‌کند.

## تنظیمات
- تصویر زمینه: `app/src/main/res/drawable-nodpi/background.jpg`
- موقعیت کادرها و فرمت تاریخ: `app/src/main/java/com/example/persiancard/CardConfig.kt`
  (مختصات به‌صورت کسری از عرض/ارتفاع تصویرند؛ برای نمایش تاریخ به‌صورت «۲۰ آبان ۱۴۰۵» مقدار `DATE_AS_WORDS` را `true` کنید.)
